## S3″ · 중성자 S(q) (2026-08-14)

두 경로로 계산해 서로 검산했다. **`sq_direct.py`(절단 없음)가 보고값**이다.

| | q_FSDP (Å⁻¹) | S(q_FSDP) |
|---|---|---|
| 중성자 회절 실험 (Zeidler PRL 113, 135501 (2014) Fig.1a ambient, digitize) | **1.50** | 1.36 |
| BKS | 1.60 (+6 %) | 1.58 (+16 %) |
| 7net-Nano-4.5 | 1.60 (+6 %) | 1.44 (+6 %) |

**위치는 두 방법이 같고, 진폭만 7net 이 실험 쪽으로 내려온다.**
q_FSDP 는 중거리 주기성이 지배 → 위상 문제 → 7net 이 못 고침 (ring 통계와 같은 결론,
**완전히 다른 경로에서 나온 독립 확인**). 진폭엔 국소 구조도 기여 → 개선됨.

### 왜 경로가 둘인가
- `sq_analyze.py` : g(r) → FT. 박스 30.4 Å 이라 r 을 15 Å 에서 자르고 Lorch 창 필요
  → **피크가 뭉개진다** (FSDP 진폭 1.44 → 1.25). 실험 곡선엔 그 처리가 없어 겹치면 불공정.
- `sq_direct.py` : 셀 정합 q 벡터로 직접 합산. 절단·창 없음. **실험과 겹칠 수 있다.**
- 두 경로 FSDP **위치가 0.3 % 이내 일치** → 창은 폭·높이만 건드린다는 확인.

### 검증
- 중성자 가중이 Zeidler 논문 표(0.0694 : 0.3880 : 0.5427)와 **소수 넷째 자리까지 일치**.
  b 값·조성·Si-O 2배·규격화를 한 번에 검사한 셈.
- 이상기체 합성 궤적에서 S(q) → 0.9996.
- digitize 실험 곡선 고k(>14) 평균 0.985 → 계통오차 약 1.5 %.

### 함정 기록
- **"q > 8 이면 S = 1" 은 틀린 기준.** 실리카 S(q) 는 22 Å⁻¹ 까지 진동한다.
  처음에 이 기준으로 "1.05 가 나왔으니 버그"라고 판단했는데, 두 경로가 소수 셋째 자리까지
  같아서 계산이 옳다는 게 드러났다. **넓은 구간 평균(q 2-10)** 으로 기준을 바꿨다.
- digitize 는 **색이 곧 의미**다. Zeidler Fig.1(a) 에서 노이즈가 있는 **빨강이 MD**,
  매끄러운 **검정이 실험**이다. 반대로 알면 결론이 뒤집힌다.
- 빨강(TS MD)은 검정 밑에 깔려 **뽑히지 않는다.** 억지로 추적하면 409점 중 269점만 잡히고
  FSDP 꼭짓점을 놓친다. 잘못된 숫자를 만드느니 뺐다.
- FSDP 위치는 잡음 때문에 추정법에 따라 **±0.02 Å⁻¹ 흔들린다**(실험 곡선은 ±0.002).
  3점 포물선 대신 **반치폭 위 무게중심**을 쓴다. 소수 둘째 자리까지만 인용할 것.
