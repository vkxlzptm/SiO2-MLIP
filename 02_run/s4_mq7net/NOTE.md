# S4 — 7net 자체 melt-quench (덱 6p 'Next step' 실행)

## 무엇을 바꾸는가

기존 결과: BKS가 melt-quench로 망 위상을 만들고, 7net은 그 위에서 relax + NVT MD만 했다.
→ ring 분포가 BKS와 **동일 구조**라 7net의 위상 예측력을 전혀 시험하지 못했다.

S4: **quench를 7net이 수행**한다. Tg를 지나며 위상이 얼어붙는 구간을 7net이 결정하므로,
처음으로 "7net이 만든 망 위상"을 얻는다.

## 고정한 것 / 바꾼 것

| 항목 | 값 | 근거 |
|---|---|---|
| 셀 | 2,160원자, V = 32,652.95 Å³ | 바꾸면 ring 잘림 길이·S(q)의 q_min·g(r) r_max가 달라져 기존 결과와 비교 불가 |
| 밀도 | ρ = 2.20 g/cm³ 고정 | BKS·7net·AIMD·실험이 모두 여기 놓여 있음 |
| 앙상블 | **전 과정 NVT** | Dechant (2026): 용융 중 NPT는 unphysical bond → 비정상 셀 변형. NPT는 300 K에서만 |
| 용융 | BKS 4,000 K 액체 인계 → 7net 재평형 20 ps | classical 액체 + MLIP 재평형은 MLIP 문헌 표준. 성립 조건은 MSD 게이트 하나 |
| 급랭률 | **2×10¹³ K/s** (100 K × 5 ps) | 문헌 범위(10¹¹~10¹³) 상한의 2배. BKS 동일률 통제런으로 상쇄 |
| 300 K 산출 | 평형 5 ps + 생산 5 ps (RDF·궤적) | 7net 본런과 BKS 통제런 모두 동일 길이 |

## 비용 (i5-11600K 6c12t, OMP=6, 실측 1,100 atom-step/s = 1.96 s/step)

| 런 | 길이 | 시간 |
|---|---|---|
| 7net MELT EQUIL 4,000 K | 20 ps | 10.9 h |
| 7net QUENCH 4,000→300 K | 185 ps | 100.7 h |
| 7net EQUIL+PROD 300 K | 10 ps | 5.4 h |
| **7net 합계** | 215 ps | **117 h (4.9일)** |
| BKS 통제런 3종 | — | ~33 min |

스레드는 6이 최적 — 12스레드 무이득, 독립 프로세스도 6개에서 2.0× 포화(메모리 대역폭 한계).
**7net 본런과 BKS 통제런을 동시에 돌리지 말 것.**

## 실행 순서

```bash
cd 02_run/s4_mq7net

# 1) BKS 통제런 먼저 (33분)
bash run_bks_controls.sh

# 2) 7net 본런
```

## ★ MSD 게이트 — 시작 후 3시간 지점에 반드시 볼 것

이 계산 전체의 성패가 여기서 갈린다. BKS 액체 구조의 기억이 지워졌는지의 판정이다.

```bash
awk '/^ *Step +Temp/{on=1;next} /^Loop time/{on=0} on&&NF==9{print $1,$2,$7,$8,$9}' \
    mq7net.log | tail -20
#   출력: step  temp  epa  MSD  maxf
#   thermo 9열: step temp press vol density pe v_epa c_msd0[4] c_maxf

# 마지막 한 줄만
awk '/^ *Step +Temp/{on=1;next} /^Loop time/{on=0} on&&NF==9{s=$1;m=$8;f=$9} \
     END{print "step",s," MSD",m,"A^2  maxf",f}' mq7net.log

# 진행 속도 (thermo 100 간격 -> 새 줄 1개 = 100 step)
a=$(grep -cE '^ *[0-9]+ +[0-9]' mq7net.log); sleep 60
b=$(grep -cE '^ *[0-9]+ +[0-9]' mq7net.log)
echo "s/step = $(echo "60/(($b-$a)*100)" | bc -l)"
```

| 판정 | 기준 (step 5000 ≈ 5 ps, 약 3 h 지점) | 조치 |
|---|---|---|
| 통과 | MSD가 시간에 **선형** + 5 ps에 10 Å² 이상 (20 ps에 수십 Å²) | 그대로 방치 |
| 실패 | MSD가 평평하거나 5 ps에 < 5 Å² | 죽이고 `velocity create 4500.0` + `fix nvt 4500`으로 재시작 (손실 3 h) |
| 붕괴 | `c_maxf`가 수십 eV/Å로 튐, epa 발산 | 외삽 실패. 온도를 **낮춰** 3,500 K로 재시도 |

융점은 추정하지 않는다 — 위 로그로 **측정**한다. MLIP 유효 융점이 BKS보다 높은지 낮은지
사전 지식이 없으므로 4,000 K에서 시작해 실패 방향에 따라 올리거나 내린다.

이후엔 하루 1회:

```bash
tail -3 mq7net.log; tail -3 mq7net_profile.dat; cat RESUME.txt
```

## 분석에서 주장할 수 있는 것 / 없는 것

**주장 가능**
- 7net vs BKS @ 2×10¹³ K/s — 초기구조·셀·급랭률·통계 길이가 전부 같다.
  ring 분포 차이가 나오면 **포텐셜에서 온 것**이다. 이 프로젝트에서 처음으로 성립하는 주장.
- BKS 5e12/2e13/5e13 세 점 → **급랭률 민감도**를 %로 제시.
  "7net은 한 속도에서만 돌렸지만, 이 구간의 급랭률 효과는 X %"까지 말할 수 있다.
- `mq7net_profile.dat`의 epa(T) 꺾임 → 7net의 Tg. BKS Tg와 비교.

**주장 불가**
- 기존 7net 220 결과(BKS 위상 위 relax)와 S4 결과의 차이를 "급랭률 때문"이라고 하는 것.
  두 계산은 급랭률 말고도 위상 생성 주체가 다르다.
- AIMD의 한계가 셀 크기라는 것 — 본 계산으로 검증되지 않는다 (기존 문서 규칙 유지).
- 급랭률 2×10¹³이 문헌 범위 안이라는 것 — **상한의 2배다.** 발표에서 명시할 것.

## 알려진 타협

1. 급랭률이 기존 BKS 220 런(5×10¹²)의 4배. CPU 117 h가 한계선이라 불가피.
   → 통제런으로 상쇄하되, 절대값은 발표에서 그대로 밝힌다.
2. 7net은 **시드 1개**만 돌린다 (117 h × N은 불가).
   → ring 분포의 통계 오차는 BKS 다중 시드로 추정해 함께 제시할 것.
3. 300 K 생산 5 ps는 기존 7net 런(3 ps)보다 길지만 BKS 220 런(50 ps)보다 짧다.
   RDF 제1피크 위치에는 충분하나, 비교 표에 길이를 병기할 것.

## 무엇을 비교했나 — BKS 4런의 성격을 먼저 정리해야 한다

S4 BKS 통제 3종(5e12 / 2e13 / 5e13)은 **같은 시드(90210)로 같은 4000 K 액체
(`melt4000.data`)를 20 ps 재평형한 동일 지점에서 갈라져 나온다.** 즉 서로 독립 표본이
아니다 — 이 셋의 폭은 **냉각률 효과**이지 통계 산포가 아니다.
(첫 판 관찰문 "BKS끼리는 2.95~3.43 %로 좁게 모여 있다"를 '통계적으로 안정적'이라는 뜻으로
읽으면 안 된다. 세 런이 닮은 건 당연하다.)

그래서 **s0_requench 의 BKS 220 런**(seed 77213, 4000 K **200 ps** 용융, 5e12 K/s)을
네 번째 점으로 넣었다. S4 BKS_5e12 와 **같은 냉각률·다른 실현**이라 BKS 의 실현간 산포를
재는 유일한 자료다. 그리고 이 구조가 바로 **기존 실험에서 7net 이 물려받았던 그 망**이라
(fig_rings.png), 같은 축 위에서 "물려받았을 때 vs 스스로 만들었을 때"가 한눈에 대비된다.

| n | 7net | BKS 평균 | BKS 최소~최대 | 차이(%p) | 오차(%p) | σ |
|---|---|---|---|---|---|---|
| 3 | **7.17** | 2.81 | 1.80 ~ 3.43 | **+4.35** | 1.44 | **3.0** |
| 4 | 15.58 | 14.92 | 14.24 ~ 15.54 | +0.66 | 1.98 | 0.3 |
| 5 | **24.82** | 30.79 | 29.97 ~ 31.61 | **−5.97** | 2.72 | **2.2** |
| 6 | 31.65 | 30.97 | 27.45 ~ 35.69 | +0.68 | 4.27 | 0.2 |
| 7 | 15.67 | 16.45 | 14.83 ~ 18.26 | −0.78 | 2.23 | 0.4 |
| 8 | 4.73 | 3.81 | 3.34 ~ 4.17 | +0.93 | 1.20 | 0.8 |
| 9 | 0.38 | 0.25 | 0.13 ~ 0.33 | +0.13 | 0.29 | 0.4 |

King ring, distinct 기준. 오차 = 계수 Poisson(7net) ⊕ Poisson(BKS 평균) ⊕ BKS 실현간 산포
(5e12 두 실현 차이 / √2, n=2 라 보수적).
평균 고리 크기(distinct): 7net **5.488** vs BKS 5.533 / 5.554 / 5.563 / 5.580.

## 검증 — 먼저 무너질 수 있었던 두 가지를 확인했다

**(1) 결합 cutoff 아티팩트가 아니다.** `ring_stats.py` 는 Si–O 결합을 RCUT = 2.0 Å 고정으로
판정하는데, 7net 구조는 Si–O 가 더 길다(1.635 vs 1.605 Å). 고정 cutoff 가 두 구조에
'같은 기준'이 아닐 수 있고 3-ring 처럼 변형된 작은 고리는 결합 판정 하나에 생겼다 사라진다.
RCUT 을 1.85 ~ 2.15 Å 로 스윕한 결과:

```
rcut     7net  BKS_2e13  BKS_5e12  BKS_5e13  BKS220_s0     (3-ring distinct %)
1.85     7.05      2.96      2.83      3.32       1.80
1.90     7.17      2.95      2.95      3.31       1.80
2.00     7.17      2.95      3.07      3.43       1.80
2.15     7.17      2.95      3.07      3.43       1.80
```

1.90 Å 이상에서 **모든 값이 완전히 평평하고 순위가 한 번도 뒤집히지 않는다.** 아티팩트가 아니다.

**(2) 결함 신호가 아니다.** 7net 이 스스로 만든 망이 결함투성이라면 3-ring 초과는 위상이
아니라 결함 이야기가 된다. 다섯 구조 전부:

| | 다리 O 비율 | 비다리 O (/1440) | 3배위 O | Si 배위≠4 (/720) |
|---|---|---|---|---|
| 7net | 99.583 % | 3 | 3 | 0 |
| BKS 2e13 | 99.722 % | 2 | 2 | 2 |
| BKS 5e12 | 99.792 % | 0 | 3 | 3 |
| BKS 5e13 | 99.653 % | 1 | 4 | 5 |
| BKS220 (s0) | 99.792 % | 1 | 2 | 1 |

원자 1~5개 수준 차이다. **7net 자체 melt-quench 망은 BKS 망만큼 깨끗하다** —
Si 배위≠4 가 0개로 오히려 가장 좋다. RESULTS 7절의 Dechant LES 결함 기준과도 무모순.

**(3) 300 K 미평형 아티팩트도 아니다.** 아래 "P300 부호 반전" 절 참조 — 300 K 10 ps
전 구간에서 압력 드리프트 < 0.02 GPa, MSD 는 소수 3자리까지 고정이다. 300 K 에서
망이 움직일 자유도 자체가 없으므로 ring 분포도 더 변하지 않는다.

## 주장 가능한 것

- **3-ring 이 유일하게 살아남는 차이다.** 7net 7.17 % vs BKS 1.80~3.43 %.
  냉각률을 5e12 → 5e13 으로 10배 바꿔도 BKS 는 2.95~3.43 % 안에서만 움직이고,
  독립 실현까지 넣어도 상한이 3.43 % 다. 7net 은 그 상한의 **2.1배**다.
  실현간 산포와 계수오차를 다 합친 보수적 오차로도 **3.0σ**.
  → *"7net 은 자기 힘으로 망을 만들 때 BKS 보다 3원환(edge-sharing tetrahedra)을
    두 배 이상 많이 남긴다. 이 차이는 냉각률로 설명되지 않는다."*
- **5-ring 은 반대 방향으로 2.2σ** (24.82 vs 30.79). 3-ring 이 늘어난 만큼을 5-ring 이
  내준 형태다. 평균 고리 크기가 7net 5.488 vs BKS 5.533~5.580 으로 작아지는 것과 일관.
- **위상 형성 효과가 실재한다는 것 자체.** 기존 실험에서 7net 은 BKS 망을 물려받아
  ring 분포가 **비트 단위로 동일**했다(RESULTS 5절). 스스로 만들게 하니 3-ring 이
  1.80 % → 7.17 % 로 **4배**가 됐다. 이 프로젝트가 처음 재는 양이고, 크기가 작지 않다.
- **6-ring 으로는 아무 말도 못 한다.** BKS 실현간 폭이 27.45~35.69 %(8 %p)로 가장 넓고
  7net 31.65 % 는 그 한가운데다. 0.2σ. 첫 판 관찰의 "7net 이 6-ring 이 가장 높다"는
  S4 세 런만 볼 때의 착시였다 — 독립 실현 하나를 넣자 사라진다.
  **"7net 망이 더 결정질에 가깝다" 류의 서술은 근거가 없다.**
- 4-ring 도 차이 없다(0.3σ). AIMD 대비 4-ring 부족(RESULTS 5절)은 위상을 스스로
  만들어도 **안 고쳐졌다.**

## 주장 불가 — 반드시 병기할 것

- **7net 은 시드 1개다.** 오차막대의 실현간 성분은 전부 BKS 에서 추정한 것이고,
  7net 이 BKS 와 같은 크기의 실현간 산포를 갖는다는 보장이 없다. 3.0σ 는
  **"BKS 의 산포를 7net 에도 적용했을 때"** 의 값이다. 117 h/런이라 반복이 불가능했다.
  → 발표 문장은 *"유의하다"* 가 아니라 *"BKS 의 실현간 산포를 기준으로 재면 3σ 수준이고,
    7net 자체 반복이 없어 이 이상은 말할 수 없다"* 로 쓴다.
- **3-ring 초과가 실물 유리에 대해 옳은가/틀린가는 이 계산이 답하지 못한다.**
  ring 분포는 회절로 재는 양이 아니라 모델에서 유도하는 양이라 **실험 계열이 없다**
  (RESULTS 5절 경고와 동일). AIMD 참조(Dechant)는 120원자·5 ps quench 라
  3-ring 통계를 신뢰할 표본이 아니다.
- **`fig_rings.png` 와 같은 그림에 섞지 말 것.** 그건 "물려받은 위상" 실험이고
  이건 "스스로 만든 위상" 실험이다. 대비시키려면 나란히 놓되 축을 명시할 것.
  (fig_rings_s4.png 패널 (c) 는 s0 점에 화살표로 그 대비를 표시해 두었다.)

## 다음에 이 결론을 강화하는 가장 싼 방법

`run_bks_sweep.sh` 의 **2e13_r2 / 2e13_r3 반복**이다 — 매칭 냉각률에서 BKS 실현 3개가
