### (1) 밀도 하락은 100 % 결합길이로 설명된다 — 위상 기여 0

Si–O가 1.6123 → 1.6360 (+1.47 %). 등방 스케일이면 ρ ∝ d⁻³ 이므로 예측 밀도비:
`(1.6123/1.6360)³ = 0.95716` → **−4.28 %**
실측 밀도비: 2.4948/2.6071 = 0.95692 → **−4.31 %**
**0.03 %p 차이.** (엄밀히는 d를 V=28552(ρ=2.5159)에서 쟀고 V₀는 28795이므로 근사)

→ **S2의 −4.31 % 밀도 하락은 전부 "결합이 길어져서"이고, 네트워크 재배열 기여는 사실상 0이다.**
0 K 이완이 위상을 못 바꾼다는 앞의 주장이 정량적으로 확인됐다.
→ 역으로, ρ = 2.607 → 2.20 (−15.6 %) 을 결합길이로만 설명하려면 d가 5.5 %(1.70 Å) 늘어야 하는데
그런 값을 예측하는 방법론은 없다. **실험값과의 격차는 결합길이가 아니라 위상(ring 통계·망 개방도) 문제다.**
그리고 **위상 차이는 리스케일로 못 고친다. 그 밀도에서 새로 quench해야 한다.**

### (2) SevenNet은 BKS→DFT 보정을 방향·크기 모두 재현한다

Farnesi Camellone et al. (arXiv:1109.2852, ρ=2.20, 300 K)의 수치와 나란히:

| | Si–O (Å) | Si–O–Si (°) | 비고 |
|---|---|---|---|
| BKS (우리, 2.607, 0 K) | 1.6123 | 149.25 ± 13.15 | |
| BKS (논문, 2.20, 300 K) | 1.61 | 152 ± 11 | **우리 BKS 셋업 검증됨** |
| **7net-nano-4.5 (우리, 2.516, 0 K)** | **1.6360** | **143.78 ± 14.03** | |
| CPMD PW91 (논문, 2.20, 300 K) | 1.65 | 146 ± 6 | |
| 실험 | 1.61 | 140–150 | |

- BKS → DFT: Si–O **+2.5 %**, Si–O–Si **−6°**
- BKS → 7net: Si–O **+1.47 %**, Si–O–Si **−5.5°**
→ **부호 일치, 각도는 크기까지 거의 일치, 결합길이는 DFT 보정의 약 59 %를 재현.**
  MLIP가 PBE 계열의 결합 과대추정 경향을 물려받았다는 증거.

**단서**: 우리는 0 K 정적, 논문은 300 K MD (열적 anharmonicity로 300 K 결합이 미세하게 김).
또 우리 Si–O–Si는 더 조밀한 계에서 잰 값이라(조밀할수록 각이 작아짐) 149.3 vs 152의 일부는 밀도 효과.
결합길이는 밀도에 둔감하므로 Si–O 비교가 더 안전하다.

## S2'-3 · BKS E–V 스캔 (2026-08-13)

| 실행 | 조건 | 결과 | 판정 |
|---|---|---|---|
| 1차 | f=0.94~1.06 (7net 창 그대로) | K₀′ −10.4, RMS 29 meV, 두 경로 0.69 % | 실패 — 창이 BKS 최소(2.31) 밖 |
| 2차 | f=0.90~1.02 (BKS 최소 중심) | RMS 86 meV, 0.70 % | 실패 — 창 문제 아니었음 |
| 3차 | pppm 1e-4 → **1e-6** | RMS 56 meV, 0.64 % | **가설 기각** — PPPM 아님 |
| 4차 | **`-var tail 1` 대조군** | 어긋남 −2,415 → −226 bar | **원인 확정** |

**진단 경로.** 3차까지 증상(`linesearch alpha is zero`, 큰 RMS)만 보고 추측했고 두 번 틀렸다.
피팅을 만지는 대신 **원자료를 직접 중앙차분**하니 (−dE/dV) − P_virial 이 부피와 무관한
**상수 오프셋**이라 잡음이 아님이 즉시 드러났다. → 절단된 Buckingham −C/r⁶ 꼬리.

**해석식.** A = 2πN² Σ x_a x_b (−C_ab/3r_c³) = −1,339,962 eV·Å³.
E_tail = A/V, **P_tail(virial) = 2A/V²** (A/V² 아님 — pairwise virial tail 은
−(2πρ²/3)∫(du/dr)r³dr 이고 u ∝ r⁻⁶ 이면 E_tail/V 의 정확히 2배).
대조군에서 LAMMPS 가 더한 값이 7개 부피 전부 소수점까지 일치.

**왜 2배가 중요한가.** −dE/dV 는 A/V² 를, P 는 2A/V² 를 받으므로 두 경로의 차이 A/V² 가
**구조적으로** 상쇄된다. 우연이 아니다.

**남은 −226 bar.** tail 보정은 r > r_c 에서 g(r)=1 을 가정하는데 실측 g(r) 은 7–8 Å 에서
아직 ±10 % 진동(0.87~1.14). 잔차 비율 9.4 % 와 같은 자릿수 → 설명됨.

**E(V) 잔차는 55.7 meV 불변.** tail 항이 V 의 매끄러운 해석함수라 계통 오프셋만 지우고
cutoff 를 넘나드는 계단 자체는 못 없앤다.

**보고값 = tail ON.** (처음엔 OFF 로 정했다가 정정. RESULTS.md §2 "어느 쪽을 보고하나" 참조)
  - "구조를 만든 MD 가 tail off" 논거는 무효 — tail 은 V 만의 함수라 **힘에 기여하지 않는다.**
    실제로 7점의 maxf 가 on/off 에서 비트 단위로 동일했다(구조가 문자 그대로 같다).
  - "0 K virial 2.3151 이 300 K NPT 2.3119 와 0.14 % 일치" 논거는 **순환논법**이었다.
    같은 장부끼리 맞는 건 당연하다.
  - BKS 원논문에 cutoff 는 없다. 절단은 구현 편의고 tail 보정은 그걸 되돌리는 것이다.
  - 유일한 객관적 지표(E/P 두 경로 일치)가 tail on 을 지지: 0.673 % -> 0.087 %.
→ **ρ₀ = 2.3442, K₀ = 34.33 GPa.** 일관성을 위해 300 K NPT 도 tail on 으로 재실행
  (`../s0_requench/in.npt_tail`, 3분) → 2.3401, 0 K virial 과 0.17 % 일치.
**단 K₀ 실질 불확도는 ±2 GPa** (tail on 34.3 ~ off 38.0). 절단 관례 하나로 10 % 움직인다.

### 배운 것

1. **증상 보고 추측하기 전에 잔차의 구조를 볼 것.** 상수면 계통오차, 무작위면 잡음.
   이걸 먼저 했으면 두 번의 헛발질(창 재조정, PPPM 조이기)을 안 했다.
2. **잘린 포텐셜에서는 −dE/dV ≠ P_virial 이다.** EOS 는 virial P(V) 를 피팅할 것.
3. **MLIP 의 매끄러운 cutoff 는 정확도가 아니라 미분가능성의 문제다.**
   7net 이 E–V 에서 18배 매끄러운 건 물리를 더 잘 알아서가 아니다. 실제로 K₀ 는 BKS 가 더 정확했다.
4. **보고 관례를 정할 땐 근거가 순환인지 먼저 볼 것.** "우리 NPT 와 맞으니 맞다"는
   같은 장부끼리의 비교라 아무것도 증명하지 않는다. 관례 선택은 **관례 밖의 근거**
   (원논문 정의, 독립 경로 일치)로 해야 한다.
5. **관례가 결과에 유리한 방향인지 소리 내어 확인할 것.** tail on 은 BKS 밀도를 나쁘게 만들어
   "MLIP 가 이긴다"는 서사에 유리하다. 근거가 독립적으로 서 있어서 택한 것이지
   결과가 좋아져서가 아니라는 걸 문서에 박아뒀다.
