# S0-3. 연구 질문 재정의 — RDF 3자 비교

> 변경: 밀도 중심 → **RDF 중심**. 밀도는 결과가 아니라 **비교의 경계조건**으로 다룬다.

## 1. 비교 대상

| | 소스 | 상태 |
|---|---|---|
| **BKS** | 기존 `sio2_quenched.data` (2160 atoms, ρ=2.607) + 신규 LAMMPS 바이너리로 재실행 | 보유 |
| **SevenNet-Nano** | `pair_style e3gnn`, `7net-nano-5.5` | S0에서 구축 |
| **AIMD** | 문헌 그림 digitize | **참고문헌 확정 필요 (아래 3절)** |

관측량: g(r) **Si–O / O–O / Si–Si**, Si–O 배위수 분포. (밀도는 3절 각주로.)

---

## 2. **가장 중요한 방법론 이슈: 밀도가 RDF를 바꾼다**

BKS 구조는 ρ=2.607, 문헌 AIMD는 보통 실험 밀도(≈2.20) 근처에서 계산된다.
**밀도가 다르면 g(r)의 2차·3차 피크와 Si–Si 거리가 당연히 달라진다.**
이걸 통제하지 않으면 "포텐셜 차이"와 "밀도 차이"가 섞여서 결론이 무의미해진다.

### → 두 종류의 런을 모두 돌린다 (둘 다 싸다)

**런 A — 밀도 고정 (NVT @ ρ=2.607, 300 K)**
- BKS와 7net-Nano를 **완전히 같은 셀·같은 원자수**로 돌린다.
- 목적: 밀도 변수를 제거하고 **순수하게 포텐셜만 비교**.
- 이게 "고전 포텐셜 vs MLIP" 질문의 정직한 답이다.

**런 B — 각자의 평형밀도 (NPT @ 0 bar, 300 K)**
- 7net-Nano가 이 구조를 어디로 끌고 가는지 본다.
- 목적: "실제로 쓸 때" 비교 + BKS cutoff 트레이드오프 서사 연결.
- 300 K 유리는 얼어 있어 원자 재배열은 거의 없지만 **셀은 움직인다** → 밀도 응답은 관측 가능.

> 런 A가 1순위. 시간이 없으면 A만으로도 프로젝트는 성립한다.

### 3자 비교표에 반드시 병기할 것
각 g(r)이 **어떤 밀도에서** 나온 것인지. 표에 ρ 칼럼 필수.

## 3. AIMD 참고문헌 후보 (확정 필요)

**핵심 제약: SevenNet-Nano는 PBE(+U) 수준으로 증류됐다. 따라서 GGA/PBE AIMD가 가장 공정한 상대다.**
LDA나 BLYP 문헌과 비교하면 "functional 차이"라는 변수가 하나 더 생긴다.

| 후보 | functional | 특징 | 적합성 |
|---|---|---|---|
| **Farnesi Camellone, Reiner, Sennhauser, Schlapbach**, arXiv:1109.2852 (2011) | **GGA** | **BKS로 만든 구조를 DFT로 이완** — 우리 워크플로와 동일. Si–O/Si–Si/O–O g(r) 전부 제시 | ★ 최우선 |
| Benoit, Ispas, Jund, Kob, *Eur. Phys. J. B* **13**, 631 (2000) | BLYP | classical+CPMD 결합, 널리 인용됨 | 차선 (functional 불일치) |
| Sarnthein, Pasquarello, Car, *PRL* **74**, 4682 (1995) / *PRB* **52**, 12690 (1995) | LDA | 고전적 표준 참조, 72원자 | 참조용 (LDA 편향) |

**작업 순서**: arXiv:1109.2852 PDF를 받아 (a) functional이 PBE인지 PW91인지, (b) 셀 크기/원자수,
(c) 밀도, (d) g(r) 그림의 축 범위를 먼저 확인. 그 다음 digitize.

### digitize 시 주의
- AIMD 셀은 보통 72~192원자 → **g(r)은 r > L/2 (≈5~6 Å)에서 무의미**. 비교 구간을 r < 5 Å로 자를 것.
- 작은 셀은 통계도 나쁘다 → 3차 피크 높이 차이를 과대해석하지 말 것.
- digitize 도구: WebPlotDigitizer. 추출한 좌표는 `03_result/aimd_gr_<pair>.csv`로 저장하고
  **출처(논문·Figure 번호·축 범위)를 파일 헤더 주석에 기록**.

### 실험값도 넣을지
중성자 회절 vitreous silica 데이터가 있으면 4자 비교가 되어 더 강해진다.
Si–O 1차 피크 위치는 문헌상 대략 1.60~1.62 Å 범위로 보고되지만,
**정확한 값과 출처는 S3에서 원문 확인 후 인용할 것** (지금 숫자를 확정하지 않는다).

## 4. MD 프로토콜 (초안, S1 속도 실측 후 확정)

```
런 A (NVT, ρ 고정):
  BKS       : 300 K, 10 ps 평형 + 30 ps 샘플링, dt=1 fs
  7net-Nano : 300 K, 동일 조건 (속도가 안 되면 샘플링 10 ps로 축소)

RDF: compute rdf, bin 0.02 Å, r_max = min(L)/2 ≈ 14.3 Å
     ave/time으로 100 step마다 누적
```

**RDF는 밀도나 확산계수보다 훨씬 빨리 수렴한다.** CPU-only여도 10 ps면 1차·2차 피크는 충분히
매끈하게 나온다 → S1에서 속도가 나쁘게 나와도 프로젝트는 무너지지 않는다.

## 5. 기존 분석 코드 재활용 체크

- RDF/배위수 코드: **입력 포맷이 LAMMPS dump인지 확인.** e3gnn 런도 같은 dump를 쓰므로
  거의 그대로 재사용 가능할 것.
- 새로 짤 것: (a) digitize한 AIMD CSV를 같은 축에 얹는 플로팅, (b) 3자 g(r) 오버레이.
- **주의**: LAMMPS 내장 `compute rdf`를 쓰면 기존 코드 없이도 g(r)이 나온다.
  기존 코드와 한 번 교차검증해서 일치하는지 확인할 것 (정규화 규약 차이 흔함).

## 6. D3

**쓰지 않는다.** 7net-Nano가 증류받은 `mpa` 채널은 PBE(+U) 단독이며 D3를 포함하지 않는다.
D3를 얹으면 학습 조건과 불일치가 생긴다. (`sevenn patch_lammps`에 `--d3` 옵션을 붙이지 말 것.)
