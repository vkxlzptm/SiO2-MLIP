# 결과 요약 — 비정질 SiO₂에 SevenNet-Nano 적용

작성 2026-08-13. 상세 근거는 각 `02_run/*/NOTE.md`, 작도 스크립트는 `04_analysis/src/`,
그림은 `04_analysis/fig/`.

---

## 한 줄

BKS(고전 포텐셜)로 만든 a-SiO₂에 범용 MLIP **7net-nano-4.5**를 적용해,
같은 밀도(ρ = 2.20 g/cm³, 실험값)에서 **BKS · MLIP · AIMD(PBE) · 실험**을 비교했다.
MLIP는 **밀도 오차를 +5.1 % → +0.85 %로 줄였고**, 국소 구조(Si–O 결합길이)는 PBE AIMD를
재현했으나 **중거리 구조(Si–O–Si)는 물려받은 위상에 묶여** 절반만 보정했다.
대가는 **CPU에서 1,244배 느린 계산**이다.

---

## 1. 계산 조건

| | |
|---|---|
| 계 | a-SiO₂ 2,160 원자 (720 Si / 1,440 O), ρ = 2.20 g/cm³, 300 K |
| 구조 생성 | BKS, 부피고정 NVT melt-quench (4000 K 200 ps 용융 → 5×10¹² K/s) |
| MLIP | 7net-nano-4.5 (7net-Omni `mpa` 채널에서 증류, PBE(+U) 계열) |
| 하드웨어 | i5-11600K 6c12t, RAM 15 GB, **GPU 없음** |
| AIMD 참조 | Dechant, Muralidhar, Ma, *J. Phys. Chem. C* **130**, 7148 (2026) — VASP/PBE, 120원자, ρ = 2.20 |

**참조 문헌 선택 근거**: PBE 범함수가 7net-nano의 학습 계보와 일치하는 유일한 a-SiO₂
AIMD 연구다. 다른 후보는 범함수가 다르다 — Camellone(PW91, arXiv only), Benoit(BLYP),
Sarnthein(LDA). MLIP 벤치마크 관행은 `05_doc/S3_MLIP_benchmark_practice.md` 참조.

## 2. 밀도 — MLIP가 고전 포텐셜 오차를 6배 줄인다  → `fig_density.png`

같은 네트워크에 두 포텐셜이 각각 "어느 부피를 원하냐"고 답한 결과.

| | ρ (g/cm³) | 실험 대비 |
|---|---|---|
| 실험 fused silica | 2.20 | — |
| **7net-nano-4.5** | **2.219** | **+0.85 %** |
| BKS | 2.312 | +5.09 % |

- Birch–Murnaghan 3차: V₀ = 32,377.9 ± 0.5 Å³, **K₀ = 43.08 ± 0.01 GPa**, K₀′ = −1.70 ± 0.03
- **독립 검증**: LAMMPS virial이 0을 지나는 밀도 2.2185 — BM3의 dE/dV = 0 지점과 **0.007 % 차이**
- K₀′ < 0 은 실리카의 이상 압축거동과 부합하나, 7점 4파라미터 피팅이라 **물리적 주장으로 쓰지 말 것**

> 자릿수 주의: 계산값의 소수 3자리는 **피팅 정밀도**일 뿐 물리적 정확도가 아니다
> (BM3 모형 선택, 단일 구조, 0 K 근사의 계통오차가 훨씬 크다).
> 발표에서는 "2.22 g/cm³ (실험 대비 +0.9 %)" 정도로 쓰는 것이 안전하다.

## 3. 구조 — 국소는 맞고 중거리는 절반만  → `fig_pdf.png`, `fig_bad.png`

### 1피크 위치 (Å) / 평균각 (deg)

| | Si–O | O–O | Si–Si | O–Si–O | Si–O–Si |
|---|---|---|---|---|---|
| 실험 | 1.610 | 2.630 | 3.080 | 109.4–109.7 | 140–150 |
| BKS | 1.605 | 2.605 | 3.155 | 109.38 | 151.89 |
| **7net-nano-4.5** | **1.635** | **2.655** | **3.135** | **109.41** | **145.05** |
| AIMD PBE | 1.630 | 2.670 | 3.030 | 109.47 | 138.65 |

### 1피크 높이 g_max / 결합각 표준편차

| | g_SiO | g_OO | g_SiSi | σ(O–Si–O) | σ(Si–O–Si) |
|---|---|---|---|---|---|
| BKS | 34.32 | 6.42 | **6.41** | 6.34 | 12.21 |
| 7net-nano-4.5 | 31.31 | 6.59 | **5.04** | **5.49** | 13.65 |
| AIMD PBE | 27.98 | 4.50 | 4.14 | 7.41 | 15.05 |

### 읽는 법

**(a) 결합길이는 PBE를 재현한다.** BKS 1.605 → 7net 1.635 (+1.9 %), AIMD 1.630.
PBE 계열의 결합 과대추정을 그대로 물려받았다. MTP(npj 2024, PBE)의 1.63과도 일치.

**(b) 밀도 하락은 전부 결합길이로 설명된다.** ρ ∝ d⁻³ 예측 −4.28 % vs 실측 −4.31 %
(0.03 %p 차이). 사면체가 길어진 결합을 각도로 흡수해 `2d·sin(θ/2)` = Si–Si 거리를
0.3 % 이내로 보존한다.

**(c) O–Si–O는 평균으로는 변별력이 없다.** 세 방법이 109.38 / 109.41 / 109.47로 0.09° 안에 든다.
정사면체 기하가 109.47°로 못 박기 때문이다. **차이는 폭에 있다** —
σ = 6.34(BKS) / 5.49(7net) / 7.41(AIMD), 35 % 차이. 7net이 사면체를 가장 단단하게 본다.
(단 AIMD의 큰 σ에는 120원자·짧은 궤적의 통계 부족과 digitize 선폭이 섞여 있다.
안전한 비교는 BKS 6.34 vs 7net 5.49 쪽이다.)

**(d) Si–O–Si가 갈리는 지점이다.** 151.89 → 145.05 → 138.65.
7net은 BKS→AIMD 간극 13.4° 중 **51 %만 메웠다.** 그리고 **7net만 실험 밴드(140–150) 안**에 있다.

**(e) Si–Si 1피크 높이가 6.41 → 5.04로 21 % 낮아진다.** 각 분포가 넓어진 게
2체 상관에 새어나온 신호다. MTP 논문의 *"semi-empirical potentials overestimate the height
of the first peak"* 와 같은 방향.

## 4. 왜 중거리는 절반만 고쳐지나 — 위상은 이완으로 안 바뀐다  → `fig_rings.png`

`ring_stats.py` 결과, **BKS 구조와 7net 이완 구조의 ring 분포가 비트 단위로 동일**하다.
0 K 최소화 + 300 K 3 ps로는 결합 교환이 일어나지 않는다(MSD 0.041 Å²).
즉 우리 Si–O–Si 145.05°는 **BKS 위상 위에 7net의 국소 물리를 얹은 값**이다.

우리 망 vs AIMD 망 (King 기준, 삼중항 계수):

| | 평균 고리 | 표준편차 | 4-ring | 6-ring |
|---|---|---|---|---|
| this work | 5.79 | 1.06 | 10.2 % | 38.4 % |
| AIMD (digitize) | 5.73 | 1.14 | **16.3 %** | 29.7 % |

평균 고리 크기는 거의 같고(5.79 vs 5.73), **AIMD 쪽이 4-고리가 60 % 더 많고 분포가 넓다.**
4-고리는 변형된 구조라 Si–O–Si가 좁으므로 방향은 맞지만, 이것만으로 6.5° 차이를
정량 설명하진 못한다.

**중요한 단서 4가지**
- **세는 방식**: 위 값은 (i,j,k) **삼중항 기준**이라 크기 n 고리가 n번 세어진다.
  서로 다른 고리 기준으로 환산하면 평균이 5.79 → **5.58**로 이동한다(개별 bin 최대 4 %p).
  논문이 어느 쪽인지 밝히지 않았다.
- **고리 정의**: King / Guttman / primitive 기준이 서로 다르다. 우리는 King을 썼고 논문은 미명시.
- AIMD 계는 120원자·L = 12.2 Å이라 큰 고리가 물리적으로 못 들어간다 (유한크기).
- AIMD quench는 **5 ps (≈4×10¹⁴ K/s)**, 우리는 5×10¹² K/s로 **100배 느리다**.
  급냉은 fictive temperature를 높이고, 실리카는 액체일수록 Si–O–Si가 좁아진다.

→ **"7net이 DFT보다 정확하다"고 쓰지 말 것.** 방어 가능한 문장은
*"이 조건의 AIMD 참조값보다 실험에 가까웠고, 그 차이는 참조 계산의 유한크기·급냉으로
설명 가능하다"* 이다.

→ 남은 절반을 메우려면 **어닐링**이 필요하다. Erhard et al.(npj 2022)의 hybrid 프로토콜이
"CHIK quench + GAP **annealing**"이었던 이유. 우리는 이완만 했다.

## 5. 비용 — CPU에서 1,244배  → `fig_speed.png`

2,160원자, i5-11600K, GPU 없음.

| | atom-step/s | 조건 |
|---|---|---|
| BKS | **1,347,000** | 6 rank × 1 thread, ρ=2.20 |
| 7net-nano-4.5 | **1,083** | 1 rank × 6 thread, ρ=2.20 |

**배수 1,244×.** cutoff 5.5 / ρ=2.607 초기 조건에서는 2,462배였다 —
**배수는 모델(cutoff)과 밀도에 크게 의존하므로 조건 없이 단독 인용 금지.**

- `atom-step/s` = 원자 수 × 스텝 수 ÷ 시간. 계 크기가 다른 계산끼리 비교하기 위한 정규화.
  역산: 5 ps × 2160원자 ÷ 1,083 = 9,972 s = **2시간 46분** (실측과 일치, BKS는 4초)
- 비용 모델: **s/step ∝ r_c³** (cutoff 스윕 4점, 오차 ≤1.2 %). 밀도 의존도 edge 수로 설명됨
  → ρ=2.20에서 4.5 모델 예측 2.026 s vs 실측 1.995 s (−1.7 %)

### 병렬화는 천장에 막혀 있다

| | 1 → 최대 | ideal |
|---|---|---|
| OMP 스레드 | **1.83×** (4에서 포화, HT 무효) | 12× |
| 독립 프로세스 | **1.98×** | 6× |

세 가지 증상이 한 원인을 가리킨다 — OMP=1에서 CPU 사용률 60 %, 스레드 1.83배 포화,
프로세스 6개에서 개당 3.03배 감속. **이 워크로드는 연산이 아니라 메모리 대역폭에 묶여 있다.**
채널 32 / 3층이라 산술 강도가 낮은 탓으로 추정. **이 머신의 천장은 약 1,000 atom-step/s이고
병렬화 전략으로는 못 넘는다.**

## 7. 이 프로젝트에서 실제로 배운 것 (실패 포함)

1. **MSD 검증 없이 melt-quench를 믿지 말 것.** 첫 구조는 승온 100 ps + 4500 K 25 ps 동안
   MSD < 1.6 Å²로 **녹지 않은 상태**였고, 녹는 순간 부피가 2.26 → 2.62로 붕괴했다.
   결과 밀도 2.607은 α-quartz(2.648) 수준 — 비정질이 결정만큼 조밀할 수 없다는 데서 발각.
2. **용융 중에는 NPT를 쓰지 말 것.** Dechant가 명시적으로 경고한다. 우리는 그걸 위반했다.
   NVT 고정 부피로 다시 하니 밀도 오차가 +18.5 % → +5.1 %로 줄었다.
3. **압력에는 운동에너지 항이 섞인다.** data 파일이 속도를 들고 다녀서 virial 검증이
   3배 어긋나 보였다. `velocity all set 0 0 0` 한 줄로 해결.
4. **`etol`이 `box/relax`를 조기 종료시킨다.** 셀 자유도 방향으로 엔탈피가 평탄해
   에너지 수렴 판정이 먼저 걸린다. `etol = 0`으로 두고 힘으로만 판정할 것.
5. **논문 그림 digitize는 범례를 조심할 것.** 범례가 플롯 박스 안에 있으면 곡선으로 오인된다.
   실제로 r ≈ 5–7 Å 구간이 들려 올라갔고, 하필 그 구간이 규격화 창이라 스케일까지 틀어졌다.
6. **속도 배수는 조건에 강하게 의존한다.** 같은 두 포텐셜인데 2,462배(cutoff 5.5, ρ=2.607)와
   1,244배(cutoff 4.5, ρ=2.20)가 모두 사실이다. 조건 없이 숫자만 인용하면 오도한다.

## 8. 한계 / 하지 않은 것

- **어닐링 없음.** 위상이 BKS 것이라 중거리 구조는 절반만 보정. 7net 어닐링은
  20 ps에 11시간이라 3일 예산 밖.
- **7net 자체 melt-quench 없음.** 진짜 "7net이 예측하는 a-SiO₂"는 미측정.
- **S(q) 미계산.** g(r)이 있으므로 푸리에 변환으로 FSDP(실험 1.52 Å⁻¹) 비교 가능.
- **excess energy 미계산.** Erhard et al.의 주요 지표(실험 78–131 meV/SiO₂). α-quartz
  단일점만 추가하면 됨.
- **AIMD 참조가 1편.** 120원자·5 ps quench의 한계를 우리가 교정할 방법이 없다.
