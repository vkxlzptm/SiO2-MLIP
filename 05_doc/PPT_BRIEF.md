## 4. 반드시 조심할 함정 (전부 실제로 한 번씩 틀렸던 것들)

### 4-1. K₀ 비교 — "BKS가 더 정확하다"고 쓰면 틀린다

BKS 34.3 vs 7net 43.2 GPa는 **각자의 평형 밀도에서 읽은 값**이라 비교가 성립하지 않는다.
실리카는 K₀′ < 0(**anomalous compression**: 조밀할수록 물러짐)이라 BKS가 6.6 % 더 조밀한
것만으로 K₀가 실험 쪽으로 끌려 내려온다. **같은 밀도에서 보면 두 포텐셜이 최대 3.2 % 차(ρ=2.20)로 겹친다.**
그리고 실험 밀도에서는 **둘 다 약 20 % 과대**다 (BKS +22.5 %, 7net +18.7 %, 실험 K = 37 GPa).

→ 슬라이드 구성: **처음엔 MLIP가 더 틀린 것처럼 보이는 결과를 보여주고, 그 다음 비교 조건을
맞춰 다시 읽는 순서**로 간다 (사용자 지시).

> ⚠ **2026-08-18 정정 — 결론의 사정거리를 줄였다.**
> 이전 판은 결론을 *"포텐셜 문제가 아니라 구조 생성 프로토콜 문제이고, MLIP로 바꿔도
> 안 고쳐진다"* 로 적었는데, 두 군데가 과했다.
>
> 1. **"안 고쳐진다"는 사실과 다르다.** 실험 대비 오차 감소는 밀도 7.8배, K 1.2배
>    (+22.5 % → +18.7 %)다. 7net이 K에서도 3.8 %p 낫다.
>    맞는 서술은 **"개선 폭이 자릿수로 다르다"**.
> 2. **"구조 생성 프로토콜 문제"는 본 계산에서 검증하지 않았다.** K가 중거리 구조에
>    지배된다는 건 문헌 일반론이고, 남는 후보도 그것만이 아니다 (0 K 근사·BM3 모형·
>    유한 셀·실제 시료와의 차이). 게다가 DFT(GGA) 문헌값도 실험보다 크다(40–46 GPa).
>
> → 현행 v10 4페이지가 쓰는 문장은 여기까지다:
> **"K 오차는 포텐셜 차이로 설명되지 않는다. 구조 생성 프로토콜로 더 줄일 수 있을지는
> 검증 필요."** (`PPT_BRIEF` §10-8 · `RESULTS.md` §2)
>
> **비교 범위 표기도 정정한다.** 두 포텐셜이 공유하는 것은 출발 구조·망 위상·셀 부피이고
> 각 부피에서 원자는 각자 이완하므로 **"같은 구조에서"가 아니라 "같은 망 위상 위에서"** 다.

### 4-2. 속도 비교 — 표현에 주의

- **MLIP가 classical MD보다 10²~10³배 느리다**는 얘기를 반드시 할 것. 유리하게만 쓰지 말 것.
- **"문헌 통상 10²~10³배" 같은 근거 없는 문장을 쓰지 말 것.** 과거에 지어냈다가 걸렸다.
  인용은 SevenNet 논문의 실제 teacher 대비 속도 향상값 + 우리 자체 측정만 쓴다.
- 배수는 조건 의존이 심하다: 같은 두 포텐셜인데 **2,462배**(cutoff 5.5, ρ=2.607)와
  **1,244배**(cutoff 4.5, ρ=2.20)가 둘 다 사실이다. **조건을 반드시 함께 적을 것.**
- `fig_speed.png` (b)의 x축 라벨은 `number of threads / processes`.

### 4-3. 밀도 숫자 혼선

**ρ = 2.20 계열(현행)만 쓴다.** BKS 2.3442 / 7net 2.2185.
**ρ = 2.607은 폐기된 v1**이다. 속도 비교 데이터 일부가 v1 조건에서 나왔으므로,
그 수치를 쓸 때는 조건을 명시하거나 현행 값으로 통일할 것.

### 4-4. melt-quench 실패의 정확한 서술

**"녹지 않았다"가 아니다.** 늦게 녹았고, **녹는 순간 NPT 때문에 부피가 붕괴**(2.26 → 2.62)한 것이다.
정확히는 "용융 중 NPT 사용"이 원인이다.

### 4-5. AIMD 참조값

Dechant et al., JPCC 2026 (published, PBE). **셀이 120원자 · L = 12.2 Å**로 작고
quench가 5 ps(≈4×10¹⁴ K/s)로 우리보다 100배 빠르다.
→ **"7net이 DFT보다 정확하다"고 쓰지 말 것.** 방어 가능한 문장은
*"이 조건의 AIMD 참조값보다 실험에 가까웠고, 그 차이는 참조 계산의 유한크기·급랭으로 설명 가능"*.
유한크기 한계를 슬라이드에 담을지는 사용자에게 확인할 것 (이전에 물었으나 미결).

### 4-6. PBE underbinding과 어긋나 보이는 결과

Si–O 결합이 늘어나는 건 PBE underbinding으로 설명되지만 K₀는 반대 방향으로 보인다 —
이건 4-1의 밀도 혼동 때문이다. **"counter-intuitive하다!"를 전면에 내세우지 말 것.**
비정질 망 구조를 모르는 사람처럼 보일 수 있다는 사용자 우려가 있었다.

- 서지 정보는 **슬라이드 하단 각주 띠**에 작은 글씨(10pt, 불가피할 때만 9pt)로 적는다.
  해당 슬라이드에서 인용한 것만 적는다.
- 번호는 **덱 전체에서 통일**한다. 3장에서 [5]면 부록에서도 [5]다.
- **실험값 출처를 부록에만 몰지 않는다.** 값이 나온 그 슬라이드 하단에 붙인다.
- 그림에서 실험 곡선/값을 겹쳐 그린 경우, 그림 바로 아래 작은 글씨로
  `[exp.: 저자 et al., 저널 volume, page (연도)]` 형식 캡션을 단다.

### 10-3. 문체 — 엔지니어 문체로 쓴다

승패·감정·훈계 어휘를 쓰지 않는다. 사실과 인과만 적는다.

| 쓰지 말 것 | 대신 |
|---|---|
| 완승 / 패배 / 이긴다 / 진다 | 오차 감소 / 과대 / 과소 / 개선 |
| 표에 속지 말 것 / 함정 | 비교 조건 불일치 / 조건을 맞춰 재비교 |
| 두 번 틀려서 한 번 맞음 | 두 오차가 상쇄 |
| 훨씬 느리다 / 어마어마하다 | 10³배 느리다 (배수로) |
| 놀랍게도 / 흥미롭게도 / counter-intuitive | (삭제) |
| ~해야 한다 / ~하지 말 것 (독자 대상 훈계) | 사실 서술로 전환 |

정도를 나타낼 땐 **형용사 대신 수치**를 쓴다.

### 10-4. 비교 서술 — 기준을 명시한다

- **AIMD를 정답으로 놓지 않는다.** "AIMD 대비 51 %만 보정" 같은 표현은
  AIMD가 참값이라는 전제를 깔므로 쓰지 않는다.
- 국소·중거리 구조의 기준은 **실험 밴드**로 잡고, AIMD는 **참조값으로 병기**만 한다.
- AIMD 참조의 한계(120원자 · L = 12.2 Å · quench 5 ps)는 **해석 슬라이드 한 곳에만** 적는다.
  여러 장에 반복하지 않는다.
- 배수·오차율은 **읽은 조건(밀도·cutoff·온도)을 반드시 병기**한다 (기존 §4-2와 동일).

### 10-5. 불릿 구성

- **중요한 순서로 나열**한다. 인과가 있으면 원인을 먼저 놓는다.
  (예: "7net 자체 melt-quench 미수행" → 그 결과인 "ring 분포가 BKS와 동일"을 뒤에)
- 같은 원인에서 나온 항목은 **하나로 합친다.** 불릿 수를 늘려 설명하지 않는다.
- 슬라이드당 불릿 6개 이내 (스킬 규칙과 동일).

### 10-6. 그림 중심

- 슬라이드당 본문 4~6줄, 그림이 면적의 절반 이상.
- 그림은 `04_analysis/fig/`의 PNG를 **그대로** 삽입한다. 크롭·재생성·스타일 변경 금지
  (§8과 동일 — 사용자가 손으로 다듬어 놓은 것).

### 10-8. 근거와 주장의 범위를 맞춘다 (2026-08-16 추가)

그림·표를 근거로 지목할 때 **그 그림에 실제로 들어 있는 비교 계열**을 확인한다.
계열에 없는 대상에 대한 주장의 근거로 쓰지 않는다.

- 실제 사례: `fig_rings.png`의 계열은 `This work (BKS = 7net-Nano-4.5)` 와
  `AIMD PBE (Dechant 2026)` 뿐이다. **실험 계열이 없다** (ring 분포는 회절 관측량이 아니라
  모델 유도량이라 애초에 실험값이 존재하지 않는다).
  → FSDP의 **실험 대비** 불일치를 설명하며 "원인은 망 위상 (우측 ring 분포)"이라고
  쓰는 것은 성립하지 않는다. 이 그림이 지지하는 문장은
  **"7net이 BKS 위상을 그대로 물려받았다"** 까지다.
- 소거법으로 얻은 결론은 **소거법임을 문장에 드러낸다.** "국소 거리로는 설명 불가"까지 쓰고,
  "원인은 X다"로 단정하지 않는다.
- 확인 절차: 결론 문장을 쓸 때마다 "이 문장의 비교 기준이 실험인가, BKS인가, AIMD인가"를
  묻고, 근거 그림의 계열과 일치하는지 본다.
