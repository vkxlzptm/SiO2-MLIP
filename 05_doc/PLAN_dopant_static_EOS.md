## 0. 한 줄

기존 **7net 자체 melt-quench 망 위상**(`02_run/s4_mq7net/prod_7net_mq.data`)에
**등가 4가 도판트(Ge⁴⁺, Ti⁴⁺)를 무작위 치환**하고, **0 K 정적 계산만으로**
E–V 곡선(BM3 fit) + 탄성 텐서를 조성별·패턴별로 뽑아 통계 처리한다.

**MD를 전혀 새로 돌리지 않는다.** 이것이 이 계획의 전부이자 존재 이유다.

## 1. 왜 이 설계인가

### 1-1. 제약이 설계를 결정했다

| 제약 | 출처 | 귀결 |
|---|---|---|
| GPU 없음. i5-11600K 6c12t | `STATUS.md` 환경 | MD 기반 조성 스윕 원천 불가 |
| **머신 천장 ≈ 1,100 atom-step/s** (메모리 대역폭 한계) | `STATUS.md` 비용 모델 | 독립 프로세스 병렬로도 **2.0×에서 포화** → 작업 분할로 못 이김 |
| `pair_style e3gnn`에 `mpirun -np ≥2` 금지 | `STATUS.md` 규칙 2 | 단일 랭크 + OMP 6. 확장 여지 없음 |
| 2160원자 force eval = **1.96 s** | S4 NOTE 실측 | **벽시계 = (총 force eval 수) × 1.96 s.** 이게 유일한 예산 방정식 |
| 조성당 full melt-quench = **117 h** | S4 NOTE 실측 | 조성 7개면 819 h = 34일. **논외** |
| 목표 예산 | 사용자 지정 | **총 계산 ≤ 1주 (실질 120 h)** |

→ 남는 선택지는 **정적 계산뿐**이다. 다행히 정적 계산은 이미 잘 돌아간다:
`in.ev220` / `in.ev_s4` 로 **E–V 7점 = 35분** (실측). 여기에 도판트 축만 얹으면 된다.

### 1-2. 왜 하필 Ge와 Ti인가

- **Ti: 코닝 ULE(7972) 그 자체다.** TiO₂ ~7 wt% 도핑 실리카가 CTE≈0인 초저팽창 유리.
  06_ppt를 코닝 분자모델링 파트에 보낸 맥락에서, 후속 주제로서 정합성이 가장 높다.
- **Ge: 광섬유 코어.** GeO₂–SiO₂ 조성별 밀도·Tg·굴절률 실험 데이터가 풍부해 대조군으로 안전.
- 둘 다 **등가(4가) 치환**이라 O 개수가 안 변한다 → 아래 1-3의 결정적 조건을 만족.
- **고전 퍼텐셜이 부실한 영역**이다 (특히 Ti의 4/5/6배위 가변성). "임의 첨가물에 empirical
  potential이 없어 uMLIP를 쓴다"는 이 프로젝트의 명분이 여기서 살아난다.
  ※ 반대로 Na/Ca/Al/B는 Pedone·Teter 등 검증된 고전 퍼텐셜이 많아 명분이 약하다.

### 1-3. ★ 이 방법이 성립하는 유일한 조건 — MO₂만 가능

0 K 최소화는 **국소 기하만 이완**시킨다. ring 통계·연결성 같은 **중거리 위상은 host 그대로**다.

- **MO₂ (Ge, Ti, Zr, Sn): 가능.** Si↔M 1:1 치환이라 O 개수·배위 골격이 보존된다.
- **M₂O₃ (Al, B) / M₂O (Na, Li): 절대 금지.** 화학량론상 O를 빼야 하는데, 0 K 최소화는
  그 vacancy를 메울 수 없다. 망이 뚫린 비물리적 구조가 나오고 탄성률이 통째로 틀린다.
  이 계열을 하려면 melt-quench 외에 길이 없다.

### 1-4. 이 계산이 답하는 질문 (그리고 답하지 못하는 질문)

**답한다 —** "동일한 비정질 망 위상에서, Si를 M으로 바꾸면 부피·강성이 어떻게 변하는가."
즉 **고정 토폴로지에서의 화학 치환 응답**. 잘 정의된 계산 실험이다.

**답하지 못한다 —** "그 조성의 실제 유리 물성." 실제 유리는 Tg를 지나며 망 자체가
도판트에 맞게 재구성된다. 그 기여는 여기 없다.

> **이 구분을 문서 첫 줄에 쓰지 않으면 리뷰어에게 정확히 여기서 맞는다.**
> 프레이밍은 "MO₂ 조성 유리의 탄성률"이 아니라
> **"a-SiO₂ 망의 등가 치환 응답 — 위상 재구성 이전의 기여분"** 이다.

### 1-5. 위상 재구성 기여도의 무료 눈금자 (기존 데이터 재활용)

`RESULTS.md` §2에 이미 있다:

| host | 7net ρ₀ |
|---|---|
| **BKS**가 만든 망 (`s2_relax`) | 2.2185 g/cm³ |
| **7net**이 만든 망 (`s4_mq7net/in.ev_s4`) | (S4-EV 결과값 — 확인 후 채울 것) |

같은 자(7net 0 K E–V)로 잰 두 값의 차이 = **망 위상 차이가 ρ₀에 주는 크기.**
이번 도판트 효과가 이 눈금보다 작으면 "위상 재구성에 묻힐 수준"이라고 정직하게 말할 수 있고,
크면 "위상과 무관하게 화학이 지배한다"고 말할 수 있다. **추가 계산 0.**

## 2. 예산 (실측 기반, 2160원자, 1 eval = 1.96 s)

### 2-1. 구조 1개당 비용

| 작업 | eval 수 | 시간 |
|---|---|---|

### 2-2. 스윕 규모와 총 벽시계

```
조성  : pure(x=0) + Ge{2,5,10 mol%} + Ti{2,5,10 mol%}   = 7
패턴  : 도판트 조성당 6개 (pure는 1개)                   = 6×6 + 1 = 37 구조
```

| 항목 | 시간 |
|---|---|
| Phase 0 결정 벤치마크 | ~2 h |
| Phase 1 인프라 (계산 아님) | ~0 h |
| Ge + pure 19 구조 × 1.82 h | 35 h |
| Ti 18 구조 × 2.91 h | 52 h |
| **합계** | **≈ 89 h ≈ 3.7일** |

**1주(120 h) 예산 안에 여유 ~30 h.** 그 여유의 용도는 §5 참조.

### 2-3. 예산에 **안 들어가는** 것 — 미리 포기할 것

| 항목 | 실비용 | 판정 |
|---|---|---|
| full melt-quench 검증런 (조성 1개) | **117 h** | 1주 예산 단독 소진. **Phase 2로 연기** |

## 3. 실행 계획

### Phase 0 — 도판트 원소 게이트 (~2 h) ★ 여기서 갈린다

7net-nano-4.5가 Ti·Ge를 산화물에서 제대로 다루는지부터 확인. **결정 셀이라 순식간이다.**

| 계 | 확인할 것 |
|---|---|
| α-quartz SiO₂ | 격자상수, K₀ — 기존 파이프라인 sanity |
| rutile TiO₂ | a, c, c/a, K₀ vs 실험(K₀≈210 GPa) |
| GeO₂ (rutile형 + quartz형) | 격자상수, 두 다형체 상대 에너지 순서 |
| (선택) α-quartz 단일점 excess energy | `STATUS.md` 남은일 §4와 겸사 |

방법: `box/relax` 전체 이완 + 등방 E–V → BM3. 셀이 작아 각각 수 분.

> **중단 조건:** 격자상수가 실험 대비 3% 이상 어긋나거나 다형체 에너지 순서가 뒤집히면,
> **그 원소는 이번 스윕에서 뺀다.** 조성 스윕을 먼저 돌린 뒤 여기서 깨지면 89시간을 버린다.

### Phase 1 — 인프라 (계산 없음)

1. **치환 스크립트** (`04_analysis/src/make_doped.py`)
   - 입력: `prod_7net_mq.data` (2160원자 = Si 720 + O 1440)
   - Si 중 n개 무작위 선택 → type 3(M)으로 변경. **O는 손대지 않는다.**
   - 개수: x mol% = n/(720) → 2%→14, 5%→36, 10%→72
   - **도판트 최소 이격 조건** (기본 M–M > 5.0 Å) 로 인위적 클러스터링 방지
     ※ 10%(72개)에서 평균 간격 ≈ 7.6 Å 이므로 5.0 Å 제약은 충분히 만족 가능
   - 패턴 seed를 파일명에 박아 재현성 확보 (`ge10_p03.data`)
2. **LAMMPS 입력 확장** — `in.ev_s4` 를 3-type으로 복제
3. **탄성 텐서 입력** 신규 작성 (§4-2)
4. **BM3 fit** 은 `04_analysis/src/ev_fit.py` 재사용 (조성 루프만 추가)

### Phase 2 — E–V + BM3 스윕 (35 h + 52 h)

Ge/pure 먼저 → 중간 결과 확인 → Ti (어닐 포함).
**순서가 중요하다.** Ge가 깨끗하게 나오면 Ti의 이상값이 "Ti의 물리"인지 "스크립트 버그"인지 구분된다.

### Phase 3 — 탄성 텐서

각 조성의 **BM3에서 나온 V₀에서** 변형을 건다. (host 밀도 2.20이 아니라 조성별 V₀)
VRH 평균 → B, G, E, ν.
**무료 내부 검증: C_ij의 VRH B 와 BM3의 K₀ 가 일치해야 한다.** 어긋나면 수렴 또는 셀 응력 문제.

### Phase 4 — 분석·작도

`fig_bulkmod.py` 스타일 유지. 조성축 그림 4~5장.

## 4. 실행 시 반드시 지킬 것

### 4-1. 기존 규칙 (`STATUS.md` 전부 유효, 특히)

- **`ulimit -s 262144`** — 안 하면 세그폴트
- **`neighbor 1.0 bin`** — edge 배열 스택 초과 방지, 결과는 소수 6자리 불변
- **`mpirun` 금지.** 단일 랭크 + `OMP_NUM_THREADS=6`
- **`velocity all set 0.0 0.0 0.0`** — data 파일 속도가 press에 조용히 섞인다
- **`etol = 0.0`** — 에너지 수렴이 힘 수렴 전에 조기 종료시킨다
- MLIP는 매끄러운 cutoff라 **tail 보정 불필요** (BKS와 달리)

### 4-2. 이번에 새로 생기는 함정

1. **★ `pair_coeff * * <pt> O Si Ti` — 원소 순서가 LAMMPS type 순서와 일치해야 한다.**
   틀려도 **에러가 안 난다** (기존 규칙 4의 3-type 판). 조용히 전혀 다른 계를 계산한다.
   → 치환 직후 단일점 에너지를 찍어보고 Si→Ti 하나당 ΔE가 물리적인지 눈으로 확인할 것.
2. **`read_data ... extra/atom/types 1`** 없이는 type 3을 못 넣는다.
3. **charge** — data가 `atom_style charge`이고 BKS 전하(±1.2/2.4)를 들고 있다.
   `pair_style e3gnn`은 charge를 안 쓰므로 무해하지만, **Ti에 전하를 안 주면 0이 된다.**
   혼동 방지를 위해 아예 `atom_style atomic`으로 변환하거나, 최소한 문서에 명시.
4. **전단 변형에는 셀이 triclinic이어야 한다.** `change_box all triclinic` 선행.
   host 셀은 orthogonal(mp-554089 유래)이라 tilt=0에서 시작하므로 안전.
5. **초기 이완 수렴 확인.** E–V 점의 `maxiter 150`은 warm start 기준이다.
   치환 직후 구조는 최소점에서 멀다 → **초기 이완만 maxiter 500**, `c_maxf` 로 수렴 확인.
   maxf가 0.05 eV/Å 아래로 안 내려가면 그 구조는 버린다.
6. **Ti는 순수 최소화로 부족할 수 있다.** Ti⁴⁺는 5/6배위를 선호해 치환 직후 국소 misfit이 크다.
   최소화는 가장 가까운 inherent structure에 갇힌다.
   → **먼저 Ti 5% 패턴 3개로 "어닐 유무" 대조를 하고 결정.** 차이가 작으면 어닐 52 h를 아낀다.
7. **패턴 간 산포를 반드시 보고할 것.** 5%(36개 도판트)에서 패턴 간 K₀ 산포가
   조성 간 차이보다 크면 그 농도는 결론을 못 낸다. **에러바 없는 조성 트렌드 그림 금지.**

## 5. 여유 30 h의 용도 (우선순위 순)

1. **QHA 시범 (7 h)** — pure host 1구조, 전진차분 Hessian 6,480 eval × 2부피점.
   VDOS + boson peak + 모드 Grüneisen → **TEC를 MD 없이.**
   실리카의 저/음의 TEC는 음의 Grüneisen을 갖는 저주파 횡파 모드(RUM) 때문인데,
   QHA는 **그 메커니즘 자체를 보여준다** — MD로 뽑은 노이즈 낀 숫자 하나보다 결과물이 낫다.
   ※ 실리카는 비조화성이 커서 QHA 신뢰 구간은 대략 300 K 이하. 조성 트렌드용으로만.
   ※ 6480×6480 실대칭 행렬 = 336 MB, 대각화 수 분. RAM 15 GB로 충분.
   ※ 되면 Ge10%/Ti10%로 확장 (+14 h) — 이 경우 여유 소진.
2. **클러스터링 대조 (6 h)** — 10% 조성에서 "최소이격 5.0 Å" vs "제약 없음" 패턴 3개씩.
   도판트 분포가 물성에 미치는 영향. 값싸고 질문이 선명하다.
3. **농도 확장** — Ge 15%, 20% (Ge는 등가성이 좋아 고농도 외삽이 상대적으로 안전)
4. **Zr 추가** — Phase 0 게이트를 통과하면. 이온반지름 축이 Ge<Ti<Zr로 길어져 트렌드가 선명해진다
