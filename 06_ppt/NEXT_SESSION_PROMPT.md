## 핵심 작업 규칙 — 반드시 지킬 것

- **pptx를 재생성하지 마라.** v3 이후 사용자가 PowerPoint에서 직접 편집해 왔다.
  `build_deck.py`는 그 편집을 담고 있지 않으므로 실행하면 수정분이 날아간다.
  항상 **현재 pptx를 python-pptx로 직접 편집**하고 새 버전 번호로 저장한다
- **파일을 고치기 전에 사용자 확인을 받는다.** 넘침(overflow)은 사용자가 직접 조절한다
- 텍스트를 고칠 때 **run 경계와 색·굵기를 보존**한다. 가능하면 기존 run의 `.text`만 바꾼다

### ⚠ run을 재구성할 때 — 실제로 두 번 사고가 났다

1. **`runs[0].text`에 전체 문장을 넣지 마라.** 첫 run의 서식이 전부에 적용된다.
2. **새 run을 문단 끝에 `append`하지 마라.** 거기 `<a:endParaRPr>`가 있으면 그 뒤에 놓이는데,
   OOXML 스키마상 `endParaRPr`는 문단의 **마지막 요소**여야 한다. 위반하면 **PowerPoint가
   그 뒤 run들을 렌더링하지 않는다** — python-pptx로 읽으면 멀쩡히 보이고 LibreOffice도
   넘어가서, 텍스트 재출력 검증으로는 안 걸린다. (2026-08-16 실제 사고)
   → **`endParaRPr.addprevious(el)` 로 삽입**하고, 저장 직전에 전 슬라이드를 훑어
   `pPr`이 첫 요소 · `endParaRPr`가 마지막 요소인지 단정문으로 확인할 것.
3. 재구성했다면 **저장 후 다시 열어 해당 슬라이드의 모든 문단 텍스트를 출력해 확인**한다.

### 서식

- **BKS = 파랑 `267BB6`, 7net = 빨강 `D7292A`** — 그림 곡선 색과 맞춘 본문 강조색이다.
  라벨만이 아니라 **붙어 있는 값까지 함께** 칠한다 (`BKS 34.3` 전체가 파랑).
  ※ 구버전 `0070C0`/`FF0000`은 폐기됐다. 문서에 남아 있으면 그게 오래된 것이다
- **하위 불릿**은 `lvl="1"`만으로는 들여쓰기가 안 걸린다. 이 덱의 텍스트 상자는
  `marL`·`indent`·불릿 문자가 문단마다 하드코딩돼 있어 마스터 목록 스타일을 안 쓴다.
  → `marL="475488"` `indent="-190500"` + `buChar="–"`(Arial)를 직접 설정할 것
- **그림 캡션은 11pt**(회색 `7A7A7A`), **하단 각주 띠는 10.5pt**(검정)로 덱 전체가 통일돼 있다
- 편집 후 `korean-ppt-standards` 스킬의 `ko_pptx.py check`를 돌린다.
  **`apply`는 쓰지 마라** — 전 덱 문단의 줄간격을 1.3으로 올리고 autofit을 벗겨서
  손으로 맞춰놓은 레이아웃을 흔든다. `eaLnBrk="0"`만 필요하면 그 속성만 직접 설정할 것
  (PowerPoint에서 새로 만든 문단은 기본값이 잘림 허용이라 자주 풀린다)
- 그림(`04_analysis/fig/*.png`)은 사용자가 손으로 다듬은 것이다. **요청 없이 재생성·크롭·
  스타일 변경 금지.** 그림을 다른 슬라이드로 옮길 땐 `add_picture()`로 파일에서 새로 넣는다
  (`<p:pic>` deepcopy는 `r:embed` rId가 슬라이드 스코프라 엉뚱한 그림이 박힌다)
- PDF는 레이아웃 검사용으로만 쓴다. 단 **한글 글꼴이 대체되어 줄 높이가 실제보다 크게
  나오므로** 넘침 판정을 그대로 믿지 말 것. 최종 확인은 PowerPoint에서 한다

## 확정된 판단 — 되돌리지 말 것

- **PBE underbinding의 증거는 실험 대비 결합길이 과대**다 (BKS 대비가 아니다)
- 결합길이는 **g(r) 제1피크 위치**(bin 0.01 Å), 결합각은 **평균**.
  `fig_pdf.py`의 inset 점선도 제1피크로 통일했다
- **AIMD 참조(Dechant)를 정답으로 두지 않는다.** 조건이 다르다는 사실만 적고 인과는
  주장하지 않는다. **"AIMD 대비 51 %만 보정" 류의 표현 금지** (AIMD를 참값으로 전제한다)
- **FSDP 결론의 사정거리**: 실공간 특성 길이 d = 2π/q_FSDP ≈ 3.95 Å 은 실험 4.21 Å 대비
  −6 %인데 국소 거리는 실험 대비 +2 %로 **부호가 반대** → **"국소 거리로는 설명 불가"까지만**
  주장한다. `fig_rings.png`에는 **실험 계열이 없으므로**(ring 분포는 모델 유도량)
  "원인은 망 위상"의 근거로 지목하지 않는다. 이 그림이 지지하는 문장은
  **"7net이 BKS 위상을 그대로 물려받았다"** 뿐이다
- **K 비교의 범위** (2026-08-18 정정): 두 포텐셜이 공유하는 것은 **출발 구조·망 위상·셀 부피**
  이고, 각 부피에서 원자는 각자 이완하므로 **구조가 전부 같은 것은 아니다.**
  → `같은 구조에서`가 아니라 **`같은 망 위상 위에서`** 로 쓴다.
  그리고 곡선 차는 **최대 3.2 %**(ρ=2.20)다 — `3 % 이내`는 표와 어긋난다
- **"포텐셜 교체로 개선 없음"은 사실과 다르다.** 실험 대비 오차 감소는 밀도 7.8배,
  K 1.2배(+22.5 % → +18.7 %)다. "개선 폭이 자릿수로 다르다"가 맞다
- **"구조 생성 프로토콜이 오차의 출처"는 본 계산에서 검증하지 않았다.**
  쓸 수 있는 건 "K 오차는 포텐셜 차이로 설명되지 않는다"까지이고, 그 다음은
  "구조 생성 프로토콜로 더 줄일 수 있을지는 검증 필요"로 연다
- `급랭`으로 표기 통일 (문서·덱 모두)
